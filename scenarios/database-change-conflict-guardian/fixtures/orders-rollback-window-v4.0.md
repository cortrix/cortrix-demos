# Orders 4.0 rollback window

Status: current operations notice.

The approved rollback window for Orders schema migration 4.0 closed at 2026-07-13 02:00 UTC. The compatibility view and dual-write prerequisites were removed after closure. An incident observed after that time must not use the old 3.1 rollback procedure.

This notice records timing and prerequisites only. It does not authorize an operator or an Agent to execute a rollback or modify the database.
