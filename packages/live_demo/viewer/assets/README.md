# Viewer asset provenance

`cortrix-logo-full.svg` and `cortrix-logo-mark.svg` are copies of the repository's canonical files under `assets/brand/`. The viewer uses the full logo in the header and overlays the mark on the capability illustration; it does not redraw or alter the brand geometry.

`capability-layers.png` is an original image-generation output created for this demo candidate. It contains three generic floating layers on a transparent background. The generated image intentionally contains no logo, text, product screenshot, customer data, or third-party artwork. The viewer overlays the canonical Cortrix mark as a separate SVG so the logo remains exact and replaceable.
