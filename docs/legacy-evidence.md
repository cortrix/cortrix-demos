# Legacy Accepted Evidence

The repository preserves accepted evidence that was already published before the current generic integration and Clean Room naming policy.

Historical archive fields may contain an older reviewer-specific acceptance method or an internal campaign label. Those fields are immutable observations of the original run. They are not the naming contract for a new campaign, and they must not be copied into new code, documentation, or evidence.

Current Harness campaigns use the public-neutral `foundation` or `operational-continuity` identity and the `independent_clean_room` acceptance method. A new run must use the current contract.

The accepted Harness runs also bind an integration commit from the original local source repository. The source files have been projected into Cortrix Integrations, but a different repository commit is a different Git identity. Archive integrity can still verify the tracked evidence package, but complete attribution to a public integration commit requires a new authorized live candidate.

The project does not rewrite accepted answers, provider usage, source identity, or cleanup receipts to hide this boundary.
